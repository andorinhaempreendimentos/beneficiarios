# Tasklist: Cadastro de Alunos pelo Responsável

- [x] **Tarefa 1: Estrutura da API (`/api/cadastro-alunos/responsavel`)** — Criar endpoint POST para receber a inscrição individual enviada pelo responsável e anexar com segurança em `respostas_conferencia_beneficiarios` com dados do aluno e responsável sem alterar tabelas oficiais.
- [x] **Tarefa 2: Interface Mobile do Responsável (`/cadastro-alunos/[nucleoId]/responsavel`)** — Desenvolver a página pública com apresentação do núcleo, dados do filho (nome, nascimento, sexo, CPF, turma) e dados do responsável (nome, parentesco, WhatsApp com máscara).
- [ ] **Tarefa 3: Comprovante e Tela de Sucesso da Inscrição** — Criar tela de confirmação com resumo dos dados do aluno, horários da turma escolhida, aviso de acolhimento e botão para cadastrar outro filho se necessário.
- [ ] **Tarefa 4: Validação TypeScript, Build e Deploy em Produção** — Executar checagem estática de tipos (`tsc --noEmit`), build, commit, push para o repositório remoto e validação ao vivo no Vercel.
